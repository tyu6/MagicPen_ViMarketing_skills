# Style Vocabulary & Imagery Guide

## Overview

This document defines the vocabulary, imagery, tone, and descriptive elements associated with each furniture style. Use these when generating copy to ensure style consistency and resonance.

---

## 1. Natural Style (自然风 / Gaya Natural)

### Core Concept
Warm, organic, earthy aesthetic that brings the outdoors inside. Emphasizes natural wood grain, soft curves, and a connection to nature.

### Tone Profile
- Warm
- Organic
- Peaceful
- Grounded
- Inviting

### Indonesian Keywords
```
natural, hangat, organik, kayu asli, nuansa alam,
tekstur kayu, warna earthy, minimalis natural, simpel
```

### Chinese Keywords
```
自然风, 原木质感, 温馨, 有机, 大地色,
木纹肌理, 亲近自然, 清新, 质朴, 回归自然
```

### English Keywords
```
natural, organic, warm, earthy, authentic wood grain,
nature-inspired, sustainable, peaceful, grounding
```

### Imagery & Associations
| Category | Elements |
|----------|----------|
| Colors | Warm beiges, soft browns, cream, sage green |
| Textures | Raw wood grain, matte finish, linen, jute |
| Atmosphere | Morning sunlight through windows, potted plants, soft cushions |
| Lifestyle | Coffee mornings, quiet reading, slow living |
| Spaces | Scandinavian homes, cozy apartments, sunlit rooms |

### Example Phrases

**Indonesian:**
- "Nuansa natural yang bikin rumah makin hangat"
- "Tekstur kayu asli yang cantik, setiap helai unik"
- "Warna earthy yang cocok buat kamar dan ruang keluarga"
- "Bikin suasana rumah jadi lebih cozy dan menenangkan"

**Chinese:**
- "原木的温润质感，让家更有温度"
- "每一道木纹都是时光的印记"
- "大地色系，营造温柔治愈的居家氛围"
- "自然纯粹，回归生活的本真"

**English:**
- "Natural wood grain that brings warmth to any space"
- "Earth-toned finish that creates a peaceful atmosphere"
- "Organic design that connects your home to nature"
- "Simple, authentic, and beautifully imperfect"

## 2. Nanyang Style (南洋风 / Gaya Nanyang)

### Core Concept
Tropical vintage aesthetic inspired by Southeast Asian colonial heritage. Combines Chinese, Malay, and European influences. Features rattan, dark woods, and eclectic patterns.

### Tone Profile
- Heritage
- Nostalgic
- Tropical
- Elegant
- Cultural

### Indonesian Keywords
```
klasik, vintage, tropis, rotan, kolonial, retro,
heritage, jaman dulu, bambu, natural elegant
```

### Chinese Keywords
```
南洋风, 复古, 热带风情, 殖民风格, 藤编,
怀旧, 异域风情, 经典, 文化韵味, 老钱风
```

### English Keywords
```
Nanyang, vintage, tropical, colonial, rattan, heritage,
retro-chic, Southeast Asian, eclectic, timeless
```

### Imagery & Associations
| Category | Elements |
|----------|----------|
| Colors | Dark mahogany, emerald green, mustard yellow, terracotta |
| Textures | Rattan weave, bamboo, carved wood details, patterned fabrics |
| Atmosphere | Ceiling fans, potted palms, veranda, humid tropical afternoons |
| Lifestyle | Afternoon tea, family gatherings, cultural appreciation |
| Spaces | Colonial homes, shophouses, tropical resorts |

### Example Phrases

**Indonesian:**
- "Nuansa Nanyang yang klasik dan timeless"
- "Rotan alami dengan finishing yang cantik, cocok buat gaya vintage"
- "Bikin rumah kayak di film jaman dulu, aesthetic banget"
- "Perpaduan modern dan klasik yang bikin ruangan unik"

**Chinese:**
- "南洋复古风情,一秒穿越旧时光"
- "藤编工艺与实木的完美邂逅"
- "热带风情的慵懒与优雅"
- "老钱风的低调奢华,历久弥新"

### Rattan-Specific Vocabulary
| Indonesian | Chinese | English |
|------------|---------|---------|
| rotan alami | 天然藤编 | natural rattan |
| anyaman rotan | 藤编工艺 | rattan weave |
| rotan sintetis | 仿藤 | synthetic rattan |
| finishing rotan | 藤编做旧 | rattan finishing |

## 3. Minimalist Style (简约风 / Gaya Minimalis)

### Core Concept
Clean lines, functional design, less-is-more philosophy. Focus on essential forms without unnecessary ornamentation. Emphasizes space and simplicity.

### Tone Profile
- Clean
- Modern
- Functional
- Calm
- Efficient

### Indonesian Keywords
```
minimalis, simpel, modern, clean, elegan, praktis,
fungsi utama, tidak ribet, sleek, contemporary
```

### Chinese Keywords
```
简约, 极简, 现代感, 干净, 利落, 实用,
少即是多, 功能至上, 线条简练, 通透
```

### English Keywords
```
minimalist, clean, sleek, functional, modern,
uncluttered, streamlined, simple, efficient
```

### Imagery & Associations
| Category | Elements |
|----------|----------|
| Colors | White, black, grey, muted pastels, monochrome |
| Textures | Smooth surfaces, matte finishes, metal accents, glass |
| Atmosphere | Organized spaces, decluttered rooms, calm environment |
| Lifestyle | Efficient living, intentional choices, mindfulness |
| Spaces | Urban apartments, modern lofts, compact homes |

### Example Phrases

**Indonesian:**
- "Desain minimalis yang simpel tapi elegan"
- "Lines bersih, bikin ruangan makin luas dan rapi"
- "Fungsional dan praktis, cocok buat rumah mungil"
- "Tidak ribet tapi tetap stylish"

**Chinese:**
- "简约不简单,每一处都有意义"
- "线条干净利落,让空间更通透"
- "Less is more,让生活回归纯粹"
- "小户型首选,实用又美观"

## 4. Modern Style (现代风 / Gaya Modern)

### Core Concept
Contemporary design with bold statements. Often features geometric shapes, mixed materials, and cutting-edge aesthetics. Appeals to style-conscious consumers.

### Tone Profile
- Bold
- Contemporary
- Trendy
- Statement
- Edgy

### Indonesian Keywords
```
modern, kontemporer, stylish, trend, bold, statement,
kece, current, urban, sophisticated
```

### Chinese Keywords
```
现代, 潮流, 前卫, 个性, 时尚, 设计感,
几何元素, 大胆创新, 城市摩登, 网红同款
```

### English Keywords
```
modern, contemporary, trendy, bold, statement,
sophisticated, urban, cutting-edge, stylish
```

### Imagery & Associations
| Category | Elements |
|----------|----------|
| Colors | Bold accent colors, metallic finishes, contrasting combinations |
| Textures | Mixed materials (wood + metal + glass), glossy finishes |
| Atmosphere | Urban lofts, creative workspaces, design-forward homes |
| Lifestyle | Career-focused, entertainment-oriented, social media savvy |
| Spaces | City apartments, creative studios, modern condos |

### Example Phrases

**Indonesian:**
- "Desain modern yang bikin ruangan jadi statement piece"
- "Trend dan stylish, cocok buat kamu yang Gaul"
- "Perpaduan material yang unik dan edgy"
- "Instagram-worthy furnitur buat rumah kece kamu"

**Chinese:**
- "现代设计感,让家与众不同"
- "大胆配色,玩转空间艺术"
- "时尚与功能的完美结合"
- "网红博主人手一件的爆款"

## 5. Rustic Style (田园风 / Gaya Rustic)

### Core Concept
Raw, unfinished aesthetic celebrating imperfection. Emphasizes reclaimed wood, distressed finishes, and countryside charm.

### Tone Profile
- Raw
- Rustic
- Country
- Authentic
- Cozy

### Indonesian Keywords
```
rustic, country, kayu reclaimed, unfinished, kasar,
antik, pedesaan, natural raw, farmhouse
```

### Chinese Keywords
```
田园风, 乡村, 原木, 做旧, 粗犷, 质朴,
实木质感, 乡村气息, 温馨田园
```

### English Keywords
```
rustic, country, raw, reclaimed, farmhouse,
distressed, unfinished, authentic, countryside
```

### Example Phrases

**Indonesian:**
- "Style rustic yang kasar tapi charming"
- "Kayu reclaimed yang bikin furnitur unik dan sustainable"
- "Nuansa pedesaan yang bikin rumah makin cozy"
- "Finishing yang raw dan natural"

**Chinese:**
- "做旧的岁月感,每一道痕迹都是故事"
- "乡村田园的温馨治愈"
- "原木的质朴与现代生活的融合"

## 6. Industrial Style (工业风 / Gaya Industrial)

### Core Concept
Urban warehouse aesthetic featuring exposed materials, metal frames, and raw finishes. Appeals to men and urban professionals.

### Tone Profile
- Raw
- Masculine
- Urban
- Edgy
- Bold

### Indonesian Keywords
```
industrial, gudang, besi, eksposur, urban, maskulin,
raw, unpainted metal, pipes, concrete
```

### Chinese Keywords
```
工业风, 裸露, 金属, 水泥, 管道, 酷帅,
仓库风格, 硬朗, 城市工业感
```

### English Keywords
```
industrial, raw, exposed, metal, concrete,
warehouse, urban, masculine, pipes, urban loft
```

### Example Phrases

**Indonesian:**
- "Gaya industrial yang maskulin dan cool"
- "Kombinasi kayu dan metal yang tough"
- "Bikin ruangan kayak warehouse urban"
- "Untuk kamu yang suka vibe cool dan edgy"

## Tone Override per Style

When user specifies tone, modify output vocabulary:

| Base Style + Tone | Effect |
|-------------------|--------|
| Natural + Premium | Emphasize rare woods, artisan details, exclusivity |
| Nanyang + Cozy | Focus on family gatherings, warm memories, comfort |
| Minimalist + Promotional | Highlight space-saving, practicality, value |
| Modern + Conversational | Use trendy slang, "kece", "gaul" expressions |
