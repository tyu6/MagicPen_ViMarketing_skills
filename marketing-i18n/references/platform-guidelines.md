# Platform-Specific Copy Guidelines

## Overview

This document provides platform-specific requirements, best practices, and optimization tips for each supported platform. Use this to ensure copy meets platform constraints and maximizes engagement.

---

## 1. Shopee Indonesia

### Character Limits
| Field | Limit | Best Practice |
|-------|-------|---------------|
| Product Title | 70 characters | Use 50-65 chars for optimal display |
| Selling Points | 500 chars each | Keep to 20-40 words per point |
| Description | 5,000 chars | 300-500 words ideal |

### Title Format
```
[Product Type] + [Key Material] + [Style/Feature] + [Benefit]

Example: Meja Makan Kayu Jati Natural 6 Kursi - Premium Quality
```

### Required Elements
1. Product type in first words
2. Key material (kayu jati, solid wood, rotan)
3. Size capacity if applicable (6 kursi, 2 pintu)
4. Quality indicators (Premium, Original, Ready Stock)

### Performance Keywords (Include 3-5)
```
termurah, terlaris, terbaik, ready stock, original,
gratis ongkir, COD, bergaransi, murah, berkualitas
```

### Emoji Usage
- Maximum 3 emojis in title
- Use for visual hierarchy in description
- Recommended: ✅ ⭐ 💯 🔥 📦

### CTA Best Practices
```
 Buruan di-order sebelum kehabisan!
✅ Ready stock, siap kirim hari ini!
 Dapat bonus [X] untuk pembelian hari ini!
```

### Pricing Display Rules
- Always show original price + discount percentage
- Example: "Rp 2.500.000 → Rp 1.999.000 (Diskon 20%)"
- Mention installment options if available (Cicilan 0%)

## 2. Tokopedia Indonesia

### Character Limits
| Field | Limit | Best Practice |
|-------|-------|---------------|
| Product Title | 60 characters | Use 45-55 chars |
| Selling Points | 300 chars each | Keep to 15-30 words |
| Description | 4,000 chars | 250-400 words ideal |

### Title Format
```
[Brand/Product Name] + [Category] + [Key Feature]

Example: Royal Teak Meja Makan Kayu Jati - Minimalis Modern
```

### Required Elements
1. Brand name if available
2. Product category
3. Key differentiator
4. Avoid repetitive keywords (keyword stuffing flagged)

### Performance Keywords
```
Original, Bergaransi, Rating 5, Terpercaya, Power Merchant,
Fast Response, Pengiriman Cepat, Kualitas Terjamin
```

### Tone Guidelines
- More formal than Shopee
- Emphasize trustworthiness and seller credibility
- Highlight ratings and reviews
- Focus on product authenticity

### CTA Best Practices
```
Pesan sekarang untuk pengiriman tercepat.
Produk original dengan garansi resmi.
Power Merchant terpercaya, belanja aman!
```

## 3. Instagram

### Character Limits
| Element | Limit | Best Practice |
|---------|-------|---------------|
| Caption | 2,200 chars | 150-300 words optimal |
| Hashtags | 30 per post | Use 8-15 relevant tags |
| Bio/CTA | 150 chars | 1-2 sentences |

### Caption Structure
```
[HOOK - First visible line]

[Story/Description]

[BENEFITS]

[CTA]

.

[Hashtags]
```

### Hook Examples (First Line)
```
- Lagi cari furnitur buat rumah idaman? ️
- Bun, meja cantik ini WAJIB kamu punya!
- Ini furnitur yang bikin rumah makin estetik
- Siapa yang lagi mood redecorate?
```

### Engagement Tactics
1. Ask questions: "Kalian lebih suka warna apa?"
2. Use countdown stickers for limited offers
3. Encourage saves: "Save post ini buat inspirasi!"
4. Tag friends: "Tag temen yang lagi cari furnitur!"

### Hashtag Strategy
``` 
#FurnitureIDN #InteriorDesign #RumahEstetik #HomeDecorID
#FurnitureMinimalis #KayuJati #MejaMakan #RumahImpian
```

### Carousel Post Rules
- 3-5 slides optimal
- First slide: Hero image + hook
- Middle slides: Details/benefits
- Last slide: CTA + pricing

```

| Album | Collections | 4-8 images with captions |

```

## 5. Xiaohongshu (小红书)

### Character Limits
| Element | Limit | Best Practice |
|---------|-------|---------------|
| Title | 20 chars | 15-18 chars + emoji |
| Content | 1,000 chars | 300-500 words |
| Hashtags | 10 per post | 5-8 tags optimal |

### Title Format
```
[Number/Adjective] + [Topic] + [Emoji]

Examples:
✨ 治愈系原木餐桌,看一眼就爱上了
🏠 小户型必看!6人位餐桌实测分享
📦 开箱合集 | 这些家具让家提升一个档次
```

### Content Style Requirements
1. **Tone**: Personal review, authentic experience
2. **Structure**: Hook → Story → Details → Verdict
3. **Keywords**: 种草, 避坑, 氛围感, 实测, 真实分享
4. **Emojis**: Use 8-12 throughout the content

### Xiaohongshu Emoji Style
```
标题常用: ✨  🏠  📦  🛋️  💡
正文常用: •  ✓  ✅  ⭐  📍  🏷️
强调: ❗ ❗❗ ⚠️ 💯
表情:  😍  🤩  ✨  🌟
```

### Tag Categories
```
#家具分享 #家居好物 #装修灵感 #原木风
#小户型家具 #餐厅布置 #餐桌推荐 #家具测评
```

### Content Templates

**种草型 (Recommendation Style):**
```
姐妹们!这家宝藏店铺我一定要分享 ✨

[Personal story/experience]

[Product highlights with details]

[Verdict and CTA]

#相关标签
```

**避坑型 (Avoid Pitfalls Style):**
```
⚠️ 买家具前必看!这些坑千万别踩

[Problem statement]

[What to avoid]

[Correct choice/better alternative]

#相关标签
```

**测评型 (Review Style):**
```
📦 真实测评 | 入手[产品名]一个月后

[Initial expectations]
[Delivery/packaging]
[Actual experience - pros]
[Cons/note-worthy points]
[Final verdict]

⭐ Overall: X/5

#相关标签
```

## 7. Content Adaptation Rules

When adapting copy between platforms, apply these transformations:

### Shopee → Instagram
- Remove: "Ready stock", "COD", pricing in caption
- Add: Lifestyle story, aesthetic descriptions
- Change CTA: "Beli sekarang" → "Link di bio"

### Instagram → Xiaohongshu
- Add: Personal pronouns, emojis, numbered lists
- Change: Hashtag style (Chinese tags)
- Tone shift: More personal, review-style

### Tokopedia → Facebook
- Expand: Add story context, more details
- Add: Social proof, customer testimonials
- Change: CTA to link format

### Any Platform → Poster Copy
- Condense to 1-2 impact sentences
- Remove platform-specific terms
- Focus on core benefit + visual appeal

---

## 8. Mobile Optimization

All copy must be readable on mobile devices:

1. **Line breaks**: Use every 2-3 sentences for readability
2. **Bullets**: Use emojis or symbols for lists
3. **Paragraphs**: Keep to 3-4 lines max
4. **Key info**: Place in first 3 lines (fold consideration)
5. **Test**: Preview on mobile before publishing
