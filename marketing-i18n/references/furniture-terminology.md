## Overview

This document provides standardized terminology for furniture materials, types, and features in Indonesian, Chinese, and English. Use correct terminology to build credibility and help customers find products through search.

## 4. Dimensions & Measurements

### Unit Conversions for Indonesian Market

| Metric | Imperial | Common Use |
|--------|----------|------------|
| cm (centimeter) | inch | Primary in Indonesia |
| m (meter) | feet | For large items |
| mm (millimeter) | - | For precision |

### Standard Dimensions

| Furniture | Indonesian | Chinese | English |
|-----------|------------|---------|---------|
| 2-seater sofa | Sofa 2 kursi | 双人沙发 | 2-seater sofa |
| 3-seater sofa | Sofa 3 kursi | 三人沙发 | 3-seater sofa |
| 4-seater dining table | Meja makan 4 kursi | 4人位餐桌 | 4-seater dining table |
| 6-seater dining table | Meja makan 6 kursi | 6人位餐桌 | 6-seater dining table |
| King size bed | Tempat tidur king size | 特大床 | King size bed |
| Queen size bed | Tempat tidur queen size | 大床 | Queen size bed |
| Single bed | Tempat tidur single | 单人床 | Single bed |

### Dimension Format in Copy

**Indonesian:**
```
Ukuran: 150cm x 90cm x 75cm (PxLxT)
Panjang: 150 cm
Lebar: 90 cm
Tinggi: 75 cm
```

**Chinese:**
```
尺寸: 150cm × 90cm × 75cm (长×宽×高)
长度: 150cm
宽度: 90cm
高度: 75cm
```

**English:**
```
Dimensions: 150cm (L) x 90cm (W) x 75cm (H)
Length: 150cm
Width: 90cm
Height: 75cm
```
