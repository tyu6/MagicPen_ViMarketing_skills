## Output Metadata Fields

Each output should include:

| Field | Description |
|-------|-------------|
| generated_timestamp | When copy was generated |
| model_version | Skill version used |
| input_hash | Hash of input parameters |
| input_mode | Whether the source was text-first or image-first |
| image_reference | Source image path/URL/attachment identifier when applicable |
| visual_confidence | Short note on how much of the product data came from visual evidence |
| character_counts | Per-field character counts |
| platform_validation | Whether copy passes platform limits |
