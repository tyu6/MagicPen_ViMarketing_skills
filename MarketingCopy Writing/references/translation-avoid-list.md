# Translation Avoid List & Common Errors

## Overview

This document lists common translation errors, awkward phrases, and direct translation patterns that should be avoided when generating Indonesian marketing copy. It serves as a guardrail to ensure natural, native-level Indonesian output.

---

## 1. Direct Translation Patterns to Avoid

### Adjective-Noun Order Errors

| ❌ Avoid (Unnatural) | ✅ Use Instead (Natural) |
|---------------------|------------------------|
| ini adalah meja yang sangat bagus | meja bagus ini / meja kece ini |
| produk berkualitas tinggi ini | produk premium ini |
| memiliki desain modern | desainnya modern |
| dengan kualitas terbaik | kualitas nomor satu / kualitas juara |

### Passive Voice Overuse

| ❌ Avoid | ✅ Use Instead |
|----------|----------------|
| Kursi ini dibuat dari kayu jati | Kursi dari kayu jati asli / Full kayu jati |
| Hal ini dapat dilihat dari finishing-nya | Finishing-nya kelihatan rapi banget |
| Produk kami dipercaya oleh ribuan pelanggan | Ribuan pelanggan udah percaya sama kami |

### Overly Formal Language

| ❌ Avoid (Too Formal) | ✅ Use Instead (Customer-Friendly) |
|----------------------|-----------------------------------|
| Silakan melakukan pembelian | Yuk, langsung order! |
| Produk ini memiliki spesifikasi | Spesifikasinya lengkap banget |
| Kami menyediakan jasa pengiriman | Kirim kami cepat dan aman |
| Untuk informasi lebih lanjut | DM aja bun, fast response! |

## 2. Chinglish/English Translation Errors

### Common Chinese → Indonesian Translation Mistakes

| Chinese | ❌ Wrong Translation | ✅ Correct Indonesian |
|---------|---------------------|----------------------|
| 优质材质 | material yang berkualitas | material premium / bahan berkualitas |
| 非常耐用 | sangat tahan lama | awet banget / keras banget |
| 简约设计 | desain yang sederhana | desain minimalis / simpel tapi elegan |
| 舒适体验 | pengalaman yang nyaman | duduknya nyambel banget / emang enak|
| 环保材料 | material ramah lingkungan | material eco-friendly / kayu sustainable |
| 高端大气 | tinggi dan atmosfer | premium dan elegan / classy |
| 性价比高 | rasio harga kualitas tinggi | worth it banget / harga sesuai kualitas |

### Common English → Indonesian Translation Mistakes

| English | ❌ Wrong Translation | ✅ Correct Indonesian |
|---------|---------------------|----------------------|
| This product is made of teak wood | Produk ini terbuat dari kayu jati | Full kayu jati asli |
| Very comfortable to use | Sangat nyaman untuk digunakan | Nyaman banget buat sehari-hari |
| Best quality guarantee | Jaminan kualitas terbaik | Kualitas terjamin, garansi lho |
| Limited stock available | Stok terbatas tersedia | Stok terbatas! Buruan |
- Free shipping to all Indonesia | Pengiriman gratis ke seluruh Indonesia | Gratis ongkir se-Indonesia |
| Easy to assemble | Mudah untuk dirakit | Praktis, gampang dirakit |

## 3. Awkward Phrases Blacklist

### Words/Phrases to NEVER Use in Indonesian Copy

| ❌ Never Use | Reason | Alternative |
|--------------|--------|-------------|
| "tersebut" (in ads) | Too formal, journalistic | Remove entirely |
| "adalah" (in product descriptions) | Unnecessary filler | Use direct style |
| "yakni" | Too formal | "yaitu" or remove |
| "tersebutlah" | Archaic | Remove |
| "oleh karena itu" | Too formal | "Jadi" or "Makanya" |
| "demi" | Too dramatic | "buat" or "untuk" |
| "konstituensi" | Wrong context | Never use |
| "pemakaian" | Too formal | "pemakaian" → "pakai" |

### Overused Marketing Words to Vary

| Overused | Better Alternatives |
|----------|---------------------|
| berkualitas | premium, juara, keren, mantap, top-tier |
| murah | terjangkau, worth it, harga bersahabat, promo |
| bagus | kece, keren, cantik, nice, aesthetic |
| tahan lama | awet, keras, kuat, solid, tidak gampang rusak |

## 4. Cultural Context Errors

### Religious & Cultural Sensitivity

| ❌ Avoid | Reason | Note |
|----------|--------|------|
| Alcohol imagery references | Indonesia is Muslim-majority | Avoid wine glass, bar content |
| Pork leather references | Non-halal | Specify "synthetic" or "cow leather" |
| Gambling references | Culturally inappropriate | Avoid "jackpot", "bet" metaphors |
| "Xmas sale" without context | Exclude non-Christians | Use " tahun baru" or "year-end sale" |

### Proper Cultural Localization

| Context | ✅ Appropriate Approach |
|---------|------------------------|
| Family scenes | Emphasize multi-generational, gathering scenes |
| Home style | Focus on Indonesian home sizes (compact, practical) |
| Payment | Mention COD, installment options prominently |
- Shipping | Highlight Jabodetabeh, major cities, express options |

## 5. Sentence Structure Fix-ups

### Long, Complex Sentences → Short, Punchy

| ❌ Avoid | ✅ Use Instead |
|----------|----------------|
| Meja makan ini dibuat dengan menggunakan kayu jati pilihan yang telah melalui proses pengeringan selama 6 bulan untuk memastikan ketahanan dan keawetan produk. | Full kayu jati pilihan, dikeringkan 6 bulan. Jamin awet! |
| Dengan desain yang minimalis dan modern, produk ini sangat cocok untuk ditempatkan di ruang makan rumah Anda yang memiliki konsep Scandinavian atau gaya yang sejenis. | Desain minimalis modern, pas buat ruangan Scandinavian! |
| Silakan hubungi kami melalui pesan langsung jika Anda memiliki pertanyaan lebih lanjut mengenai produk yang kami tawarkan ini. | Ada pertanyaan? DM aja, fast response! |

### Redundant Words Removal

| ❌ Redundant | ✅ Concise |
|--------------|-----------|
| Diproses dengan proses finishing | Difinishing dengan rapi |
| Material bahan kayu | Full kayu |
| Ukuran dimensi | Ukuran |
- Warna color | Warna |

## 6. Platform-Specific Errors to Avoid

### Shopee Errors

| Error | Fix |
|-------|-----|
| Generic titles without keywords | Include: product type + material + key feature |
- Missing "Ready stock" | Add to title or first selling point |
| No emojis in description | Use bullets with ✅ ⭐ 💯 |
| Forgetting COD mention | Always mention if available |

### Tokopedia Errors

| Error | Fix |
|-------|-----|
| Too casual tone | More formal, trust-building |
| Missing warranty info | Add "Bergaransi" prominently |
| No seller credibility mention | Add "Power Merchant" if applicable |
| Keyword stuffing | Use natural keyword placement |

### Instagram Errors

| Error | Fix |
|-------|-----|
| Caption too long without breaks | Add line breaks every 2-3 sentences |
| Starting with product name | Start with hook/question |
| No hashtags or too many | 8-15 relevant hashtags |
| Missing CTA | Include clear call-to-action |

### Xiaohongshu Errors

| Error | Fix |
|-------|-----|
| No emojis in Chinese copy | Add 8-12 emojis throughout |
| Too salesy | Use personal review tone |
| Missing tags | Add 5-8 relevant Chinese tags |
| No personal pronouns | Use "姐妹们", "我" for authenticity |

## 7. Number & Price Formatting

### Indonesian Price Format Rules

| ❌ Wrong | ✅ Correct |
|----------|-----------|
| Rp 1,999,000 | Rp 1.999.000 (dots for thousands) |
| IDR 1999K | Rp 1.999.000 or "Budget 2 jutaan" |
| 1.999.000 rupiah | Rp 1.999.000 |
| Rp. 1.999.000 | Rp 1.999.000 (no dot after Rp) |

### Number Word Usage

| Context | Use Numbers | Use Words |
|---------|-------------|-----------|
| Prices | Rp 1.500.000 | - |
- Dimensions | 150 cm × 90 cm | - |
| Guarantees | 1 tahun, 2 tahun | - |
| Small counts | - | dua pilihan, tiga warna |

## 8. Punctuation Guidelines

### Indonesian Punctuation (Important Differences)

| Correct Usage | Example |
|---------------|---------|
| For emphasis, Indonesian uses "lho", "dong", "banget" | Bagus banget, lho! |
| Exclamation points used freely in marketing | Stok terbatas! |
| No Oxford comma | A, B dan C (not A, B, dan C) |
| Quotation marks for slogans | "Best seller bulan ini" |

### Avoid

| ❌ Error | ✅ Correct |
|----------|-----------|
| Multiple exclamation marks (!!!) | Single exclamation (!) |
| Formal quotation marks (「」) | Standard quotes (" ") |
| Ellipsis (...) in marketing | Use dashes (—) or remove |

## 9. Testing Your Indonesian Copy

### Quick Quality Check

Ask these questions before finalizing:

1. ✅ Would a local Indonesian seller say it this way?
2. ✅ Is the tone appropriate for the platform?
3. ✅ Are there any direct translation leftovers?
4. ✅ Does it sound conversational and engaging?
5. ✅ Are prices and numbers formatted correctly?
6. ✅ Are cultural sensitivities respected?

### Red Flag Phrases (Immediate Revision Needed)

```
If you see these phrases, rewrite immediately:
- "Produk ini adalah..."
- "Yang memiliki..."
- "Dengan kualitas..."
- "Dapat digunakan untuk..."
- "Silakan..."
- "Untuk informasi lebih lanjut..."
```

## 10. Revision Examples

### Before & After Transformation

**Original (Unnatural):**
```
Meja makan ini memiliki desain minimalis yang modern. 
Produk ini terbuat dari kayu jati yang berkualitas tinggi. 
Dengan finishing yang rapi, meja ini cocok untuk ruangan Anda. 
Silakan lakukan pembelian sekarang untuk mendapatkan harga spesial.
```

**Revised (Natural, Selling):**
```
Meja makan minimalis modern, full kayu jati premium! 
Finishing rapi, cocok buat ruang makan estetik kamu.
Ukuran pas untuk ruangan Indonesia.
Buruan order, ada harga spesial nih!
```

**Key Changes Made:**
1. Removed "ini memiliki" → Direct style
2. "Kayu jati yang berkualitas tinggi" → "kayu jati premium"
3. "Silakan lakukan pembelian" → "Buruan order"
4. Added "pas untuk ruangan Indonesia" (localized)
5. Added conversational tone "nih"
